Файлы для Mini App рыбного магазина

Содержимое:
- 8 оптимизированных фотографий в WebP
- products.json — данные товаров, цены, единицы измерения и имена изображений

При загрузке в GitHub положите эти файлы рядом с index.html (в корень репозитория).
Пути к картинкам в JSON — имена файлов, например shrimp-northern.webp.

Важно: цены и названия скопированы из сведений, переданных владельцем магазина. Перед публикацией нужно подтвердить их актуальность.
